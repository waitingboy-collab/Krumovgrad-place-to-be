# Krumovgrad — place to be

Атлас на интересните места в община Крумовград: природа, история, вода и храмове в Източните Родопи.
Граждани предлагат места, а администраторът ги одобрява (Supabase).

- На живо: https://krumovgrad-place-to-be.vercel.app
- `src/index.html` — сайтът (`src/places.html` е същата страница)
- `src/admin.html` — админ панел за одобряване на места и видеа
- Хостинг: Vercel, коренна папка `src`
